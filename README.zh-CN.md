## 主要功能

One AI Shortcut 是一个用于改善日常 AI 聊天工作流的个人 Chrome 扩展。目前提供跨服务发送消息和附件、开启新对话以及统一聊天快捷键等功能。

- 将文字、图片和文件发送到六个 AI 聊天服务的任意组合。
- 每个服务都从一个全新的对话开始。
- 通过文件选择或拖放添加最多 5 个附件；也可以只发送附件。
- 优先复用已打开的网站标签页，未打开时创建后台标签页。
- 各服务独立发送；未确认提交时自动重试，只在失败或需要手动操作时通知。
- 在支持的网站中使用统一的新建对话快捷键。

扩展没有运行时依赖、后端服务、数据分析或独立账号系统。

## 支持的 AI 聊天服务

| 服务 | 网站 | 消息 | 附件 | 新对话 |
| --- | --- | :---: | :---: | :---: |
| ChatGPT | `chatgpt.com` | ✓ | ✓ | ✓ |
| Claude | `claude.ai` | ✓ | ✓ | ✓ |
| Gemini | `gemini.google.com` | ✓ | ✓ | ✓ |
| Grok | `grok.com` | ✓ | ✓ | ✓ |
| DeepSeek | `chat.deepseek.com` | ✓ | ✓ | ✓ |
| Doubao | `doubao.com` | ✓ | ✓ | ✓ |

附件是否可用仍取决于各服务当前的产品能力、账号、地区、文件格式和上传限制。

## 安装

1. 下载或克隆本仓库。
2. 在 Chrome 中打开 `chrome://extensions`。
3. 开启**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择本项目文件夹。

更新代码后，请重新加载扩展，并刷新已经打开的 AI 聊天页面。

## 使用

1. 登录准备使用的 AI 服务。
2. 打开扩展弹窗。
3. 输入消息、添加附件并选择目标服务。
4. 点击 **Send**，或按 `Command+Enter` / `Ctrl+Enter`。

Chrome 接收后台任务后，弹窗会立即关闭。扩展随后为每个目标服务准备新对话、上传同一组附件、提交消息，并根据页面状态确认是否成功发送。全部成功时不会显示通知。

扩展会优先复用当前窗口中的现有标签页，并将其导航到新对话；没有匹配标签页时创建非活动标签页。单个服务失败不会影响其他服务。

### Doubao 降级处理

Doubao 偶尔会完成消息和附件准备，但拒绝自动提交。此时扩展会激活已经准备好的标签页，并提示手动按 Enter。这是针对未提供稳定提交接口的第三方页面所保留的降级路径。

## 快捷键

- `Shift+Command+O` / `Ctrl+Shift+O`：在当前支持的网站中新建对话。
- `Command+K` / `Ctrl+K`：使用各网站的搜索命令查找对话；扩展会把 Gemini 映射到这组统一快捷键。

如果新建对话快捷键与其他扩展冲突，可以在 `chrome://extensions/shortcuts` 中修改。

## 隐私与权限

消息和附件只在本地内存中处理，并仅发送给弹窗中选中的服务。扩展不会保存消息、附件或使用数据，不会截取 AI 回复，也不会把信息发送到开发者控制的服务器。

| 权限 | 用途 |
| --- | --- |
| `tabs` | 查找、复用、导航或创建受支持网站的标签页。 |
| `notifications` | 提示发送失败或需要手动完成提交。 |

被选中的服务会按照各自的条款和隐私政策处理内容。完整说明见 [PRIVACY.md](./PRIVACY.md)。

## 使用限制

- 每次最多 5 个附件，单个文件不超过 10 MB，合计不超过 20 MB。
- 必须事先登录准备使用的服务。
- 支持的文件类型和账号功能由各 AI 服务决定。
- 发送依赖第三方网站的页面结构，网站更新后可能需要维护适配。
- 复用标签页会把当前页面切换到新对话；历史记录仍由对应服务管理。

## 开发与测试

项目不需要构建，也没有运行时依赖。在仓库根目录运行 Node.js 测试：

```bash
node --test tests/*.test.js
```

架构、各网站适配、手动测试与发布检查见[开发说明](./docs/DEVELOPMENT.md)。
