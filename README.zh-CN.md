## 项目简介

One Shortcut for AI Chat 是一个轻量、无运行时依赖的 Chrome 扩展。它可以把同一条消息、图片和文件发送到多个 AI 聊天服务的新对话，并为所支持的网站统一“新建对话”快捷键，同时保留统一的对话搜索体验。

扩展完全在 Chrome 本地运行，不包含后端服务、数据分析或独立账号系统。

## 主要功能

- 将同一条消息、图片和文件发送给六个 AI 聊天服务的任意组合。
- 支持文件选择和拖放添加附件；发送前显示图片缩略图、文件名和大小。
- 默认全选所有服务，也可以逐个取消选择。
- 优先复用当前窗口中第一个匹配的标签页。
- 没有打开相应网站时，在后台创建新标签页。
- 每次发送前进入新的对话页面。
- 各网站独立执行，单个网站失败不会中断其他网站。
- 后台确认接收任务后立即关闭弹窗；逐站确认是否真正提交，必要时采用对应网站的重试策略，仅在失败或需要手动操作时显示系统通知。
- 在所有支持的网站上使用统一的新建对话快捷键。

## 支持的 AI 聊天服务

| 服务 | 网站 | 批量发送 | 附件 | 新建对话 | 搜索对话 |
| --- | --- | :---: | :---: | :---: | :---: |
| ChatGPT | `chatgpt.com` | ✓ | ✓ | ✓ | `Command+K` / `Ctrl+K` |
| Claude | `claude.ai` | ✓ | ✓ | ✓ | `Command+K` / `Ctrl+K` |
| Gemini | `gemini.google.com` | ✓ | ✓ | ✓ | `Command+K` / `Ctrl+K` |
| Grok | `grok.com` | ✓ | ✓ | ✓ | `Command+K` / `Ctrl+K` |
| DeepSeek | `chat.deepseek.com` | ✓ | ✓ | ✓ | `Command+K` / `Ctrl+K` |
| Doubao | `doubao.com` | ✓ | ✓ | ✓ | `Command+K` / `Ctrl+K` |

Gemini 原本使用不同的搜索快捷键，扩展会进行映射，因此六个网站均可使用同一组快捷键。

附件栏中的勾表示已经实现自动上传流程。具体可用的文件类型、大小、账号权限和处理速度仍由各 AI 服务决定。

## 发送流程

1. 弹窗在本地校验并读取所选文件，然后请求后台工作线程创建发送任务。
2. 后台确认接收任务后，弹窗立即关闭，后续发送继续在后台执行。
3. 对于每个选中的服务，扩展优先复用当前 Chrome 窗口中位置最靠前的匹配标签页；没有匹配标签页时创建非活动标签页，并进入新对话。
4. 内容脚本上传附件、填写消息并提交，然后等待页面证据，例如 URL 变化、输入框清空、新的用户消息出现或发送按钮持续变为不可用。
5. 标准适配在未发现提交证据时，会重新获取当前输入框和发送按钮并重试一次。全部成功时保持静默；只有失败或需要手动操作时才显示 Chrome 通知。

## 各平台实现差异

六个网站没有统一的公开接口，因此扩展有意采用不同的适配方式：

| 服务 | 附件实现 | 发送实现 | 运行特点 |
| --- | --- | --- | --- |
| ChatGPT | 通过 `DataTransfer` 写入普通页面文件输入框 | 点击原生发送控件、等待提交证据，失败后重试一次 | 通常能立即确认提交。 |
| Claude | 通过 `DataTransfer` 写入普通页面文件输入框 | 点击原生发送控件、等待提交证据，失败后重试一次 | 可用文件类型取决于 Claude 当前账号和页面能力。 |
| Gemini | 在页面主 JavaScript 环境中设置文件输入框并触发 change 事件 | 使用原生发送控件、等待提交证据，失败后重试一次 | 复用页面时保留 Google 账号的 `/u/<account>` 路径。 |
| Grok | 通过 `DataTransfer` 写入普通页面文件输入框 | 点击原生发送控件、等待提交证据，失败后重试一次 | 上传后输入框可能被替换，因此发送前会重新获取。 |
| DeepSeek | 通过 `DataTransfer` 写入普通页面文件输入框 | 等待发送控件可用，再提交、确认并重试一次 | 附件处理可能明显较慢；扩展会延长等待，避免过早点击。 |
| Doubao | 在页面主 JavaScript 环境中设置文件输入框并触发框架事件 | 等待附件预览和控件稳定，依次尝试表单、按钮、指针/框架、键盘事件，并进行最终稳定控件重试 | 防御性处理最多，但确定性最低。 |

### Doubao 的限制

Doubao 偶尔会完成文字和附件准备，却不接受自动提交动作，附件上传后或输入组件重新渲染时更容易发生。扩展会重新获取最新输入框和发送按钮、等待状态稳定、尝试多种页面级提交方式，并且只在观察到提交证据后才报告成功。如果仍然失败，扩展会激活 Doubao 标签页并发送通知，提示手动按 Enter；此时文字和附件通常已经准备完成。

这是有意保留的降级路径。Chrome 扩展生成的 DOM 事件不属于可信用户事件，而 Doubao 没有提供稳定的公开提交接口。在不增加更广泛浏览器控制权限的前提下，无法保证 100% 自动发送。

## 安装方法

1. 下载或克隆本仓库。
2. 在 Chrome 中打开 `chrome://extensions`。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**。
5. 选择本项目文件夹。

拉取新版本后，需要在扩展卡片上点击 **重新加载**，并刷新已经打开的 AI 网站页面，使新的内容脚本生效。

## 使用方法

1. 预先登录准备使用的 AI 服务。
2. 点击 Chrome 工具栏中的扩展图标。
3. 输入文字、添加图片或文件，也可以只发送附件而不输入文字。
4. 保持全部选中，或只选择需要的服务。
5. 点击 **Send**，也可以按 `Command+Enter` / `Ctrl+Enter`。

对于每个选中的服务，扩展会把位置最靠前的匹配标签页导航到新对话页面。没有匹配页面时，会创建一个非活动标签页。如果同时打开了多个匹配页面，优先使用当前窗口中的标签页。

## 快捷键

- `Shift+Command+O` / `Ctrl+Shift+O`：在当前支持的网站中新建对话。
- `Command+K` / `Ctrl+K`：在六个支持的网站中搜索对话。

如果新建对话快捷键与其他扩展冲突，可以在 `chrome://extensions/shortcuts` 中修改。

## 隐私与权限

消息和附件只会在发送过程中短暂保留在内存中，并发送给弹窗中选中的 AI 服务。扩展不会保存这些内容、收集使用数据，也不会把信息发送到开发者控制的服务器。被选中的 AI 服务会按照各自的隐私政策处理收到的内容。

| 权限 | 用途 |
| --- | --- |
| `tabs` | 查找并复用已经打开的 AI 网站标签页，或创建新的后台标签页。 |
| `notifications` | 发送失败时列出失败的 AI 聊天服务；全部成功时不显示通知。 |

完整说明见 [PRIVACY.md](./PRIVACY.md)。

## 当前限制

- 每次最多选择 5 个附件，单个文件不超过 10 MB，所有附件合计不超过 20 MB。
- 各 AI 服务可能根据当前产品、账号等级或地区限制拒绝某些格式或大小；对应网站会被标记为发送失败，但不会中断其他网站。
- 必须事先登录准备使用的 AI 服务。
- 发送功能依赖第三方网站当前的页面结构；网站更新后可能需要调整选择器或事件处理方式。
- Doubao 自动提交属于尽力而为；页面忽略扩展生成的提交事件时，系统通知会提示手动按 Enter。
- 被复用的标签页会进入新对话；原对话是否保留在历史记录中由对应 AI 服务决定。

## 开发与测试

项目没有运行时依赖，也不需要构建。自动化测试仅使用 Node.js 内置模块：

```bash
node --test tests/*.test.js
```

项目采用 Chrome Manifest V3，并将弹窗脚本全部放在外部文件中，以符合内容安全策略。架构、网站适配方法和发布检查清单见[开发说明](./docs/DEVELOPMENT.md)。
